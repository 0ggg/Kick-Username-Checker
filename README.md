## Arabic Guide / الدليل العربي

### 1. المتطلبات
- Python 3.8+
- تثبيت الحزم المطلوبة:
``bash
pip install -r requirements.txt
``

### 2. طريقة التشغيل
1. تثبيت الحزم المطلوبة:
   ``bash
   pip install -r requirements.txt
   ``
2. تشغيل الأداة:
   ``bash
   python main.py
   ``
   - سيطلب منك `Enter Username Length :` ادخل الطول
   - سيطلب منك `Threads :` ادخل عدد الثريدات (مثال 3)

### 3. المخرجات
- الطباعة المباشرة:
  - `[+] Available : username`
  - `[-] Taken : username`
  - `[-] Rate Limited : username`
